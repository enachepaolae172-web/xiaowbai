# Node 6 conditional modules and report rules

- The model proposes evidence profiles for all five extension modules.
- Application code independently evaluates minimum evidence and discards ineligible output.
- Skipped modules retain a reason and missing-evidence list; they do not render empty tables.
- Target customers, product direction, channel direction, value-chain choice, and 30/60/90-day
  validation actions are labeled as analytical recommendations and remain evidence-linked.
- Markdown citations use `[Sxx]`. Unknown IDs fail validation, unused sources are reported, and source
  conflicts remain visible as counterpoints or unknowns.
- Only enabled extension modules appear in the report body.
